# Syntetyczna próbka mowy polskiej (CC0 / generated)

Audio w tym katalogu jest celowo ignorowane przez Git.
Aby utworzyć około 30-sekundowy plik mowy polskiej:

    python scripts/generate_polish_sample.py

Po tym poleceniu w katalogu input pojawią się:
- sample_pl_30s.ogg — syntetyczny polski lektor (eSpeak)
- sample_pl_30s.reference.txt — referencyjny tekst do porównywania ASR

Oryginalne rozmowy, nagrania sądowe, audio z danymi osobowymi ani ich
transkrypcje nie powinny znajdować się w historii Git.
